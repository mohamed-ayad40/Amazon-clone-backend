## ✨ Features

- **Stripe Integration** — Server-side payment intent creation and webhook handling
- **Order Management** — Create and retrieve orders linked to user accounts
- **Firebase Admin** — Verifies user tokens for protected endpoints
- **CORS & Security** — Configured for secure cross-origin requests from the frontend

---

## 🛠️ Tech Stack

Node.js · Express.js · Stripe · Firebase Admin SDK

---

## 🚀 Getting Started

```bash
git clone https://github.com/mohamed-ayad40/Amazon-clone-backend.git
cd Amazon-clone-backend
npm install
# Add .env with STRIPE_KEY and Firebase credentials
npm start
```
